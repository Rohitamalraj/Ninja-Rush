# 🥷 Ninja Rush

A fast-paced browser-based ninja action game built with React, TypeScript, and Phaser.js. Survive for 30 seconds while defeating waves of rogues!

## 🎮 Game Features

- **30-Second Rounds**: Quick, intense gameplay sessions
- **4 Enemy Types**: Basic, Fast, Armored, and Boss rogues
- **6 Power-Ups**: Rapid Fire, Double Shuriken, Freeze Bomb, Invincibility, Score Multiplier, Health Scroll
- **Combo System**: Chain kills within 2 seconds for bonus points
- **Progressive Difficulty**: Game gets harder as time progresses
- **Frenzy Mode**: Chaos mode activates in the final 5 seconds
- **High Score Tracking**: Local storage persistence

## 🎯 Controls

- **Arrow Keys** or **A/D**: Move left/right
- **Spacebar**: Throw shurikens
- **ESC**: Pause game

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Phaser 3** - HTML5 game engine
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Zustand** - State management
